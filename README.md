# TechStore — магазин компьютерной техники

Исходный код настольного приложения для учёта товаров, справочников,
покупателей и продаж магазина компьютерной техники.

## Возможности

- Товары, категории, производители, поставщики и покупатели.
- Добавление, изменение и удаление записей справочников и товаров.
- Поиск по данным текущего раздела.
- Оформление продажи с несколькими позициями и проверкой остатка.
- Расчёт суммы продажи и списание товаров в одной транзакции.
- Экспорт данных раздела в PDF, JSON и CSV.
- Главная страница со статистикой магазина и товарами с небольшим остатком.

## Технологии

C++17, Qt 6, Qt Quick/QML, Qt SQL, SQLite и CMake.

База состоит из семи связанных таблиц: `Categories`, `Manufacturers`,
`Suppliers`, `Products`, `Customers`, `Sales`, `SaleItems`.
При первом запуске приложение самостоятельно создаёт файл базы и заполняет
его демонстрационными данными. Отдельный сервер базы данных не требуется.

## Сборка и запуск

Потребуются Qt **6.5 или новее** с компонентами **Qt Quick, Qt Quick Controls 2
и Qt SQL**, компилятор C++17 и CMake **3.21 или новее**. В комплекте Qt должен
быть доступен SQLite-драйвер `QSQLITE`. Для Windows проект проверялся
с Qt 6.10.2 и MinGW 13.1.

### Через Qt Creator

1. Скачать проект: **Code → Download ZIP**, затем распаковать архив.
2. Открыть `CMakeLists.txt` в Qt Creator.
3. Выбрать установленный комплект **Desktop Qt 6** и настроить проект.
4. Собрать и запустить приложение кнопкой **Run**.

Для MinGW используйте путь к проекту и папке сборки латиницей,
например `C:\Projects\Computer-Store`.

### Через командную строку

В терминале с настроенным компилятором и CMake выполните:

```text
cmake -S . -B build -DCMAKE_PREFIX_PATH="<каталог установленного комплекта Qt>"
cmake --build build --config Release
```

Вместо текста в угловых скобках укажите путь к своему комплекту Qt:
это каталог, в котором находятся `bin`, `lib` и `lib/cmake`.

В Windows при сборке через Ninja исполняемый файл находится
в `build\TechStore.exe`; при использовании генератора Visual Studio —
в `build\Release\TechStore.exe`.

Для запуска EXE вне среды Qt подготовьте библиотеки утилитой из того же
комплекта Qt. Пример для сборки через Ninja:

```text
windeployqt --qmldir qml build\TechStore.exe
```

При переносе подготовленной программы копируйте её папку целиком.
Подробнее: [сборка с CMake](https://doc.qt.io/qt-6/cmake-get-started.html),
[развёртывание в Windows](https://doc.qt.io/qt-6/windows-deployment.html).

## База данных и экспорт

По умолчанию `techstore.sqlite` создаётся в каталоге данных приложения,
который определяет Qt через `QStandardPaths::AppDataLocation`.
Экспортированные файлы сохраняются в подпапке `exports` рядом с базой.

Переменная окружения `TECHSTORE_DATA_DIR` позволяет задать отдельную папку
для базы — например, для демонстрации или тестирования.

## Самопроверка

В `main.cpp` предусмотрен режим `--self-test`. Он проверяет тестовые данные,
поиск с JOIN, CRUD категории, ограничения внешнего ключа,
откат некорректной продажи, списание остатка и экспорт в три формата.

Запускайте его с **новой отдельной папкой** в `TECHSTORE_DATA_DIR`:
проверка создаёт продажи и изменяет демонстрационные данные.
Через `TECHSTORE_LOG_FILE` можно указать файл журнала проверок.
Код завершения `0` означает успешное прохождение самопроверки, `2` — ошибку.
